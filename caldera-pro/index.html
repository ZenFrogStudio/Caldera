Agent access (MCP)

Let Claude Desktop drive the app. You set how far.

An agent on your computer can check your schedule, add tasks or fill in a budget. It works over a small server that only listens on your own machine (127.0.0.1), so nothing is exposed to the network.

  1. OffNothing. The server doesn't run.
  2. Read onlySee your projects, schedule and budgets, but change nothing.
  3. Read + writeAlso add, edit and delete tasks, blocks, budgets and plans. Ctrl Z undoes its recent changes.
  4. FullAlso arm scheduled prompts and Manager task jobs, and start a research run or an AI import, which Caldera asks you to allow first.

Private by design

Your work stays on your machine.

There is no telemetry and no cloud sync. Your whole workspace is a folder on your own computer.

%APPDATA%\caldera
  • Online only when you askCaldera reaches a service only when you use a feature that needs it: your AI provider, your mail server, your chat server, or the wallet's network. Installed copies also check for updates, with no install ID.
  • Backups without lifting a fingerA copy of your workspace is kept at each start: the last 10 starts, and one a day for 14 days.
  • Nothing gets written overIf the data file is ever damaged, Caldera keeps it and offers to put the newest good copy back.
  • Leave whenever you likeSettings › Data exports your workspace to a folder you choose, or erases everything Caldera stored.

Questions

Good to know.

What do I need to run it?

Windows 10 or later, 64-bit. Run the installer and choose whether to install for just you or for everyone on the PC.

Do I need an AI subscription?

No. The calendar, lenses and boards all work without one. The AI features are optional and use what you already have: Claude Code, Codex or OpenCode, Ollama for local models, or a Claude or OpenAI API key.

Windows SmartScreen warned me. Is that expected?

Yes. The installer isn't code-signed yet, so SmartScreen may warn you on first run. Click More info › Run anyway.

How does it update?

Caldera keeps itself up to date. Settings › Account › Updates picks Automatic (download in the background, install when you quit) or Manual.

What happens to my data if I uninstall?

Uninstalling leaves your workspace folder in place. To remove it, use Settings › Data to erase everything Caldera stored.

Is there a free version?

Yes. The free edition is the original Caldera photo calendar, on GitHub.
